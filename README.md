# Transportation Simulator(新設路線シミュレーター)

既存の公共交通ネットワーク(鉄道・バス)に新設路線計画を入力し、
利用者数の予測や所要時間の短縮効果を計算・可視化するツール(日本国内対象)。

## ステータス

設計フェーズ。設計書は [docs/DESIGN.md](docs/DESIGN.md) を参照。

## 概要

- 地図上で新設路線(駅・線形・表定速度・運行間隔)を入力
- 四段階推定法の簡易版(発生集中 → 重力モデル → 機関分担 → 配分)で需要を予測
- 整備前後の比較により、新線利用者数・断面交通量・所要時間短縮・
  等時圏の拡大・時間便益(円換算)を算出し、地図とチャートで可視化
- 複数シナリオ(ルート案)の比較に対応

## 技術スタック(予定)

- フロントエンド: React + TypeScript + MapLibre GL JS + deck.gl
- バックエンド: Python + FastAPI
- 計算エンジン: numpy / pandas / GeoPandas / igraph
- データ: 国土数値情報(鉄道 N02・駅別乗降客数 S12)、e-Stat メッシュ人口 ほか
