# データ準備スクリプト

## network.json(既存鉄道ネットワーク)

```bash
python3 scripts/prepare_data/build_network.py --area keihanshin
```

- 既定ソースは npm パッケージ **japan-train-data 0.6.0**(MIT License、駅データ.jp 系の
  路線・駅順・座標データ。2017年頃時点)。`node` コマンドが必要。
- 生成物 `data/keihanshin/network.json` はリポジトリにコミット済みのため、
  通常は再実行不要。
- 駅間所要時間は「直線距離 × 迂回係数 1.1 ÷ 表定速度」の概算。表定速度・運行間隔は
  路線カテゴリの既定値+主要路線の個別上書き(スクリプト内の定数を参照)。
- 新快速などの直通運転は `THROUGH_PAIRS` の路線ペアに対し、共有駅で乗換なしの
  直通リンク(1分)を張ることで近似している。

### 既知の制限(japan-train-data ソース)

- データが 2017 年頃時点(おおさか東線全通・JR総持寺・夢洲延伸などは未収録)
- 新幹線・神戸市営地下鉄海岸線が含まれない
- 速達列車の停車駅は区別されない(路線単位の表定速度で近似)

### 公式データ(国土数値情報 N02)への切替

`--source n02` は Phase 2 で実装予定(`n02.py` に実装計画を記載)。
国交省サーバー(nlftp.mlit.go.jp)へのアクセスが必要なため、リモート実行環境では
動作しない場合がある(ローカルで実行すること)。

## population_mesh.csv(500m メッシュ人口・任意)

`data/<area>/population_mesh.csv` を置くと、等時圏サマリーに圏内人口が表示される。

フォーマット(ヘッダー必須):

```csv
mesh_code,population
513546861,1234
```

- `mesh_code` は 9 桁の 4次(500m)メッシュコード
- 入手元の例: e-Stat「統計GIS」の国勢調査 500m メッシュ人口
  (京阪神は 1次メッシュ 5134/5135/5136/5234/5235 付近)。
  ダウンロードした txt/csv から `KEY_CODE` と総人口列を上記 2 列に整形する。
